A one-line roast of the gadget I use every day — my phone. It waits until
5% battery to warn me it's dying, then spends the last 5% telling me about it.

`main.py` (Python 3.13, stdlib only) writes the single roast line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
